# HextechBrawl 3.1.0 · 武器绑定肉鸽

3.1.0新增：每张普通海克斯卡直接显示88×88预览框中的原版武器图标，旁边显示武器名称、颜色/类别及本次获得等级。图标对应实际发放的已保存候选ID，查看预览不生成物品、不改变随机数。原图来自res/cardIcons.png，通过原生Assets.getItem引用，不复制或覆盖资源。图标缺失时保留名称并明确提示。动效保留；本次仅构建检查，实机视觉由用户测试。

本版普通海克斯卡同时标注“强化效果 + 将获得的武器 + 该武器颜色/分类”。有效确认后直接获得卡上的武器并绑定；后续每次正常海克斯选择，对此前绑定的每件武器继续叠加成长。保留三卡弹出、回弹、悬停和确认退场动效。

## 开局：颜色 → 分类

每局自动赠送一张定向卷轴，分两步完成，不生成地面拾取物：

1. 红/紫/绿三选一，决定武器必须包含的原版颜色标签。
2. 近战/远程二选一，决定武器分类。本局锁定，后续重随不能改变。

没有第三个盾牌池。盾牌必须先满足颜色条件，再作为兼容项进入选定的近战池或远程池。

双色武器只要一个标签匹配就允许。例如原版ThrowingTorch（投掷火把）为战术/暴虐：红色+远程允许，紫色+远程也允许；红色+近战不允许。纯紫武器不会进入红色池。颜色使用tier1/tier2集合匹配，与标签顺序无关。

原版武器group=4为近战，5为远程，6为盾牌。当前目录由只读res/data.cdb提取114件可掉落单槽武器/盾牌。双槽武器及其副手暂不加入候选，避免一次选择隐式占用或破坏两个槽位。采用原始数据标签；其他模组修改标签时，此目录不会动态跟随。

颜色同时沿用相应基础路线：红=兵器大师，紫=奥术工程师，绿=壁垒守卫。以前版本的六路线随机开局被本版颜色/分类选择替代。

## 选择即获取

每次普通三选一生成三个强化及三个对应武器，候选武器尽量不重复。金币、细胞、诅咒等契约代价仍然有效：资源不足则不扣费、不消耗候选，也不发武器。

- 确认后通过原版库存接口直接将新武器放入指定位置，不要求再捡一次。
- 按W或点击底部按钮指定替换位置，在两个武器槽和已有背包武器之间切换。选择背包位置时，新武器进入背包。
- 替换位置的旧物品会掉落在玩家脚边，保留其等级和绑定身份，不会直接删除。
- 没有携带武器时，新物品加入空武器槽。
- 当前指定的是双槽武器时会拒绝交易并保留选择；请先卸下它或指定其他位置。
- 新武器基础等级采用当前地图的原版map.lootLevel；Boss Rush采用原版getItemLevel，限制在1～27级。难度与关卡对掉落等级的影响由原版生成结果体现，不重复添加难度加成。锻造卡的额外等级在新获得武器上结算，上限30级。

三个候选的武器分配随候选一起保存。退出重进不免费改变武器；重随同时重抽强化与武器，并保持颜色/分类约束。世界自然掉落不被禁用，池限制仅针对海克斯提供的武器。

## 绑定成长

按物品permanentId绑定，保存其获得时的正常选择次数。

- 新获得物品初始绑定层数为0。
- 此后每次正常选择，所有旧绑定物品各增加1层。
- 每层给该物品的原生攻击增加4%伤害（最多+100%）、1.5%攻速（最多+45%），同类叠加。
- 同名新物品是另一个绑定，不能继承旧物品层数。
- 被替换后捡回同一件旧物品，可继续使用它原有的绑定成长。
- 开局颜色、分类选择不计层；重随不计层；选牌失败不计层。

绑定额外伤害按攻击的sourceItem识别，攻速按Weapon.item识别；不为无关物品追加绑定倍率。原有海克斯的全局强化、羁绊及代价继续按其描述生效。绑定成长不会反复修改物品等级，避免换图/读档重复乘算。

## 穿墙与多发

- 相位穿墙（黄金、奥术，最高1级）：两类池都可出现。绑定近战武器在原版攻击范围内忽略视线遮挡；绑定Bullet弹丸设置原生ignoreWalls穿过墙体；这些绑定攻击伤害降低10%。不更改敌人AI视线。特殊武器的独立碰撞/自动瞄准机制仍可能限制效果，需实机确认。
- 散射弹幕（黄金、猎杀，最高1级）：仅远程池出现，卡上仅配对兼容的弓弩、桶炮或投掷火把；不与盾牌或未适配的光束/范围法术配对。一次原生发射重复为3组，额外两组约±7.45度散射，每发伤害45%，全部命中理论为原来的135%。原生多箭武器按“3组”处理，不能误解为固定3根箭。
- 额外两组不额外花费弹药，也不能回收产生额外弹药；只在普通玩家原生武器发射中触发，有调用深度保护，父子shoot不会重复增殖。自动触发的附加攻击不再次发射。
- 两项能力对本局已绑定且兼容的武器生效。重置本局后消失，不修改原版物品文件。

## 保留的策略规则

每次正常选择获得一层开局所选主色的原版属性，保持原版武器/属性伤害曲线。删除按选牌次数自动叠加的伤害×1.03、生命×1.02，避免重复成长；核心等级的少量额外成长保留，不免费治疗。六流派2/4种羁绊、核心碎片升级和有次数限制的重随保留。

锻造：金币精锻支付300金币，新武器额外+1级；细胞熔铸支付15细胞，额外+2级；诅咒锻造增加10诅咒，额外+3级。以上均同时红紫绿各+1。

资源交易：染血借贷获得1000金币并增加12诅咒；灵魂透支获得30细胞并减少治疗；赎罪支付600金币减少10诅咒并降低伤害；细胞献祭支付25细胞换三色各+2并减少生命；背负厄运增加15诅咒换伤害。原版诅咒死亡仍生效，不灭核心不能阻止它。

负面取舍保留，例如迅捷打击攻速+25%但伤害-15%，蛮力生长伤害+30%但攻速-10%。开局路线为红武器伤害+15%/受伤+10%，紫附伤+25%/武器伤害-10%，绿生命+20%/攻速-10%。具体等级、收益和代价见卡面。

## 操作、存档与升级

1/2/3或鼠标选卡；方向键+Enter也可确认。W指定替换位置，R重随；F6打开核心，Tab切换核心/选牌，G消耗碎片升级核心；Esc暂存选择并恢复游戏。

颜色、分类、候选武器、绑定身份和层数随DCCM SaveData保存，新局重置。物品本身由原版库存/地图保存。旧绑定掉落后若关卡被卸载且物品不再可回收，记录不会凭空重新生成该物品。

旧版本升级后保留已有物品、强化和待选奖励，补一次颜色/分类确认；已有候选和已消耗重随次数保留，并补充符合新池的候选武器。旧物品不会自动绑定，需要从本版海克斯获得的实例才有绑定成长。
